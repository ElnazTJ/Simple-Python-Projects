# 🐍 Simple Python Projects

A collection of fun and simple Python projects I built while learning and experimenting with Python.

These projects were mainly created as practice while following the **Bro Code Python course**, helping me get familiar with Python syntax, functions, GUI development, and basic programming concepts.

## 🎯 Projects

* 🌦️ **Weather App** — A small weather application that gets weather information based on a city.
* ⏰ **Digital Clock** — A simple digital clock built with PyQt5.
* ⏱️ **Stopwatch** — A basic stopwatch application with a graphical interface.
* 🔔 **Alarm** — A simple alarm clock project.
* 🎮 **Hangman** — A classic Hangman word-guessing game.
* 🧩 **Other Mini Projects** — Small experiments and exercises created while learning Python.

## 🛠️ Technologies

* Python
* PyQt5
* Basic Python concepts
* GUI programming

## ⚠️ Note

The **Weather App** relies on an external weather API. Depending on your network or region, access to the API may be unavailable, so the app may require a different network connection to work properly.

## 📚 Purpose

These projects are part of my Python learning journey and were created mainly for practice, experimentation, and having fun while learning.
